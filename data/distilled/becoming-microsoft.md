# 纳德拉传 - 10 分钟精读

## 开篇问题

纳德拉接手微软时，大家说微软已经死了。你身上有没有那种「被认为已经死了」的项目？

## 一、从傲慢到谦逊：改变微软文化

沃尔特·艾萨克森在《纳德拉传》中写道：纳德拉接手微软时，微软被批评傲慢。

微软的产品很强，但文化被诟病为"精英主义"。员工之间竞争激烈，缺乏合作。

纳德拉改变文化的方式是：从"知道答案"到"提出好问题"。

在纳德拉之前，微软文化是"我是对的，你是错的"。纳德拉改变为"我可能错了，我们讨论一下"。

## 二、成长型思维：固定型思维 vs 成长型思维

纳德拉受卡罗尔·德韦克影响，推行"成长型思维"。

固定型思维：我就是这样的人。我不擅长这个，永远不擅长。

成长型思维：我可以变得更好。我不擅长这个，但我可以学习。

德韦克的研究显示，成长型思维的人更可能成功，因为他们愿意面对挑战、从失败中学习。

纳德拉在微软推行成长型思维：
- 承认错误：我错了，我来修正
- 学习新东西：我不懂这个，我来学
- 帮助他人：你遇到什么困难，我帮你

## 三、云优先：从 Windows 公司到云公司

纳德拉接手时，微软被批评"错过了移动互联网"。微软的操作系统在手机上没有市场，云计算落后于亚马逊 AWS。

纳德拉的战略是"云优先，移动优先"。他停止把微软当成操作系统公司，而是把微软当成云服务公司。

Azure 现在是全球第二大云平台，仅次于 AWS。微软的市场价值从 1300 亿增长到 2.8 万亿。

## 四、实践建议

- 从"知道答案"到"提出好问题"
- 培养成长型思维
- 拥抱变化，不抗拒变化
- 关注客户，不关注自己
- 建立学习文化
- 承认错误，快速修正
- 帮助他人成功

**核心一句话**：领导不是知道答案，而是问对问题。成长型思维是组织成功的基础。

知识型组织：我们已经有所有答案。

## 十一、微软内部文化改革的具体措施

纳德拉接手后推行了一系列具体改革：

**取消排名制度** — 微软曾实行强制排名（stack ranking），员工之间互相竞争以获得更高评分。这导致了严重的内耗。纳德拉取消了这一制度，改为团队协作评价体系。

**推广共享笔记** — 要求每位高管每周写一篇博客式的共享笔记，公开讨论公司的进步和挑战。这创造了透明沟通的文化。

**设立成长型思维培训** — 全员参加卡罗尔·德韦克的成长型思维工作坊，学习如何以"还没有"代替"不行"。

**开放源代码运动** — 微软从封闭转向开放，支持 Linux、Python 等开源项目，收购 GitHub。这一战略转向改变了外界对微软的看法。

## 十二、云优先战略的三个阶段

**第一阶段：重新定义产品**
纳德拉首先让微软停止把 Windows 视为唯一核心。Azure 被重新定位为第一优先级产品。

**第二阶段：跨平台扩张**
微软推出了 Office for iPad、Office for Android、Chrome 扩展。这意味着微软愿意在任何平台上提供服务，不管是不是微软的系统。

**第三阶段：AI 领先**
微软投入 10 亿美元支持 OpenAI，并将 AI 深度集成到 Azure 和所有产品中。现在 Azure 是 AI 基础设施的重要提供者。

## 十四、微软的开源战略：从封闭到开放

纳德拉上任后做了两件震惊科技圈的事：

**第一件事：支持 Linux**
过去微软视 Linux 为死敌。纳德拉说："Linux 跑在我的云上。"他推动了 Azure 全面兼容 Linux。

**第二件事：收购 GitHub**
2018 年微软以 75 亿美元收购 GitHub，这曾是 Microsoft 最讨厌的开源平台。收购后纳德拉承诺保持 GitHub 的独立性。

这两个举动标志着微软从一个封闭的技术巨头变成了一个开放的生态系统参与者。市值也从那时的 5000 亿增长到了今天的 2.8 万亿。

## 十五、文化变革的具体成果

纳德拉的文化改革带来了哪些具体成果？

**员工满意度提升** — Glassdoor 上微软的员工评分从 3.4 提升到 4.2
**产品创新加速** — Azure 云服务的发布速度提高了三倍
**跨部门协作增强** — 各产品线之间的协同效率明显改善
**人才吸引力增强** — 顶尖工程师更愿意加入微软

这些都证明了"正确文化带来正确结果"。

## 十七、纳德拉的管理哲学：从命令到服务

纳德拉的管理风格与前任形成鲜明对比：

**鲍尔默时代** — 命令与控制型管理，强调KPI和排名
**纳德拉时代** — 服务与支持型管理，强调赋能和成长

纳德拉说："管理者的任务是清除员工前进道路上的障碍，而不是给员工设定障碍。"

这种转变的意义不仅在于内部效率，更在于对外形象——微软从一个傲慢的科技巨头变成了一个开放的创新伙伴。
